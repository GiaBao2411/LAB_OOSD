## 🚀 Cách xem và chạy một bài Lab

```bash
# 1. Clone repository
git clone https://github.com/GiaBao2411/LAB_OOSD.git

# 2. Di chuyển vào repo
cd LAB_OOSD

# 3. Mở thư mục bài Lab muốn xem (ví dụ LAB2)
cd LAB2
```

Với bài có dự án C#, mở file `.sln` / `.slnx` bằng **Visual Studio** và nhấn **F5** để chạy.

Với tài liệu và sơ đồ, mở file `.docx` bằng **Word / WPS Office**, file `.pdf` bằng trình đọc PDF và file `.drawio` bằng **Draw.io / diagrams.net**.
