## 🚀 Cách chạy một bài Lab

```bash
# 1. Clone repository
git clone https://github.com/GiaBao2411/LAB_OOSD.git

# 2. Di chuyển vào repo
cd LAB_OOSD

# 3. Mở thư mục bài Lab muốn xem (ví dụ LAB2)
cd LAB2
```

Sau đó mở file `.sln` / `.slnx` bằng **Visual Studio** và nhấn **F5** để chạy.
