BAI 5 - QUAN LY HO SO BENH AN (WinForms, .NET Framework 4.7.2)

CACH CHAY
1. Giai nen file zip ra o dia (khong mo truc tiep trong file zip).
2. Mo QuanLyBenhAn.sln bang Visual Studio 2022, bam F5.
   Lan chay dau tien chuong trinh TU TAO database QuanLyBenhAn va du lieu mau
   (chay file Database\QuanLyBenhAn.sql).

NEU BAO LOI KET NOI SQL SERVER
- Mo App.config, sua Data Source cho dung may cua ban, vi du:
    (localdb)\MSSQLLocalDB     -> LocalDB (mac dinh)
    .\SQLEXPRESS               -> SQL Server Express
    .                          -> SQL Server ban day du
- Hoac mo Database\QuanLyBenhAn.sql trong SSMS, bam Execute, roi chay lai.

TAO LAI DATABASE TU DAU
- Trong SSMS: DROP DATABASE QuanLyBenhAn; roi chay lai chuong trinh.

CAU TRUC
  Data/      Db.cs, DbInit.cs
  Services/  Models.cs + 6 Service (DanhMuc, HoSo, PhieuKham, ToaThuoc, LichHen, ThongKe)
  Forms/     FormHelper.cs + 8 Form (.cs va .Designer.cs)
  Database/  QuanLyBenhAn.sql
