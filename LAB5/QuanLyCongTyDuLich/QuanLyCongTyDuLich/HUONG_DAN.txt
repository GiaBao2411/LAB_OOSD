BAI 6 - QUAN LY CONG TY DU LICH (WinForms, .NET Framework 4.7.2)

CACH CHAY
1. Giai nen file zip.
2. Mo QuanLyCongTyDuLich.sln bang Visual Studio 2022.
3. Bam F5. Lan chay dau tien chuong trinh TU TAO database QuanLyCongTyDuLich
   va du lieu mau (chay file Database\QuanLyCongTyDuLich.sql).

NEU BAO LOI KET NOI SQL SERVER
- Mo App.config, sua Data Source cho dung may cua ban, vi du:
    (localdb)\MSSQLLocalDB     -> LocalDB (mac dinh)
    .\SQLEXPRESS               -> SQL Server Express
    .                          -> SQL Server ban day du
- Hoac mo Database\QuanLyCongTyDuLich.sql trong SSMS va bam Execute, roi chay lai.

TAO LAI DATABASE TU DAU
- Trong SSMS: DROP DATABASE QuanLyCongTyDuLich; roi chay lai chuong trinh (hoac chay lai file .sql).
